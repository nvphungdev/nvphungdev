## About

I build practical software for web products, operations, and developer workflows. I like small, clear systems: useful interfaces, reliable automation, and codebases that are easy to keep improving.

Most of my work sits around full-stack TypeScript, Python tooling, Web3 products, AI integrations, and cross-platform apps. I am especially interested in internal tools, virtual workspaces, automation, blockchain-powered workflows, and integrations that remove repetitive work.

## What I Work On

- Web applications and internal tools with TypeScript.
- Automation, QA, and integration work with Python.
- Blockchain, Web3, dApps, wallet flows, and smart-contract integrations.
- AI-powered tools, LLM integrations, assistants, and workflow automation.
- Cross-platform apps with React Native, Flutter, and Electron.
- Backend adapters, APIs, and real-time app infrastructure.
- Open-source forks, experiments, and focused utility projects.
